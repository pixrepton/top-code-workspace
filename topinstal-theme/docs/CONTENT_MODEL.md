# Content Model

## CMS-Managed

- Page title and body copy.
- Hero supporting copy when stored as excerpt/custom fields later.
- Media and alt text.
- FAQs, testimonials and trust elements once migrated out of Elementor.
- SEO title, meta description, canonical and schema through SEO plugin.
- Contact data through WordPress settings/theme mods.

## Code-Managed

- Layout, breakpoints, grid behavior and component composition.
- Header/footer structure.
- Cards, buttons, hero and section presentation.
- Animation and interaction behavior.
- Accessibility states and focus behavior.

## Plugin-Managed

- Calculator: `[heatpump_calc]`.
- Configurator: `[konfigurator]`.
- PDF generator: `[top_instal_offer_generator]`.
- Lead widget: `[topinstal_lead_widget]`.
- Curve AI: `[krzywa_ai]`.
- RAG chat: `[hvac_rag_chat]`, `[hvac_chat]`.

Do not duplicate plugin content or business claims in theme templates. If copy
needs improvement, migrate it into CMS fields or page content first, then update
theme presentation around it.
