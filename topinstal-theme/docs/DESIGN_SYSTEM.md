# TOP-INSTAL Design Foundation

## Direction

Quiet, technical, service-company UI. The site should feel modern and competent,
not like a generic page-builder landing page.

## Tokens

Primary token files:

- `assets/css/tokens.css`
- `theme.json`

Current foundation:

- ink: `#18212f`
- red: `#c92127`
- amber: `#e7b56f`
- blue: `#176b87`
- soft surface: `#f4f7f8`
- white: `#ffffff`
- radius: 4px controls, 8px cards/media
- max container: 1180px

## Component Rules

- Buttons use clear action text, 44px minimum target height.
- Cards use max 8px radius and no nested cards.
- Header is dense and practical: brand, nav, phone, calculator CTA.
- Mobile starts from touch targets and readable text, not a squeezed desktop nav.
- Functional widgets are framed by theme layout but their internal behavior stays
  plugin-owned.
- Avoid one-hue palettes, decorative blobs, oversized marketing-only sections and
  hidden mobile-only functionality.
